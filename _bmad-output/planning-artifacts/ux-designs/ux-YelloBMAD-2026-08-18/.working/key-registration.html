Key screen — registration to first Task

UJ-1’s ninety-second path, and the first real test of the terse voice. The load-bearing constraint here is a negative one: the climax is that Ravi “never saw an empty state asking him to configure something.” And SM-C2 makes time-in-application a counter-metric — so the success condition for this whole flow is Ravi closing the tab.

1Register

Two fields. No plan picker, no team-size question, no “what will you use Yello for?” — there is nothing to configure because a Space is created for him.

One message for every cause, and never “no account found” or “wrong password”. AD-23 goes further than copy: the response must be identical in duration too, so a registration attempt against an existing address still performs the password hash it would otherwise skip. The interface must not branch here, including on timing.

What is deliberately missing from all four screens, because UJ-1’s climax and SM-C2 rule each of them out:
  • No Status or column setup step — the defaults are simply present.
  • No onboarding checklist, progress meter or “3 of 5 steps complete”.
  • No product tour, tooltips or coach marks.
  • No sample Project or demo Tasks to delete later.
  • No invite-your-team prompt. Ravi has no team, and UJ-1 ends with no notion that Yello is collaborative.
  • No celebration on first Task. Closing the tab is the win.
