The underlying decision remains deferred exactly as recorded below. Original finding follows. — `tests/Yello.Tests.Shared/SqlServerContainerFixture.cs:30-35`, `:64-67`. Severity: medium. The class is a plain fixture with no `[CollectionDefinition]`, no assembly-level fixture and no `WithReuse(true)`. xunit constructs one instance per collection (or per class under `IClassFixture`), and the five suites run as five separate Microsoft.Testing.Platform *processes* — so cross-suite sharing is impossible without container reuse or an external orchestrator. The doc comment that states the topology as settled fact should be softened in the meantime so a later story does not build on it.

Severity: low. `ProjectReference` output flows transitively by default and nothing in the solution sets `ReferenceOutputAssembly` or `PrivateAssets`, so the gate's "exact equality" describes what each project *declares*, not what it can compile against. Worth revisiting the first time a production row gains an edge.
